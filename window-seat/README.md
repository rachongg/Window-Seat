# Window Seat

A rainy car-window game. Guide the raindrop Pip down the glass by wiping paths in the fog.

- **Puzzles**: endless levels. The first 20 are hand-made; after that new ones are generated and test-played so 3 stars are always possible.
- **Race a friend**: two players back raindrops racing down the window.
- **Draw**: draw faces in the fog.

The whole game is one file, `index.html`. No build step.

## Play it

Open `index.html` in a browser, or host it with GitHub Pages:
Settings → Pages → Source: deploy from branch → `main` / root. Then open the Pages link on your phone and use **Add to Home Screen** for a full-screen app.
